# 路线图

长期目标：在受控游戏引擎环境中，让 NPC 利用视觉观测和空间记忆，自主决定动作、完成任务并可重复评测。

| 阶段 | 工作 | 通过标准 |
|---|---|---|
| 0：可协作基线 | 公开源码、上传规则、离线 CI、文档 | 新伙伴可克隆并跑离线测试；敏感材料不入库 |
| 1：可复现采集 | UE 资产初始化、固定场景与数据协议 | 干净环境可生成带独立标定的 RGB-D 会话 |
| 2：SLAM 回放 | 适配 ORB-SLAM3、固定输入顺序、真值隔离 | 报告覆盖、跟踪失败、尺度、误差及时间 |
| 3：实时空间层 | UE 传帧、位姿返回、地图记忆接口 | 有延迟/丢帧预算和重定位验收 |
| 4：决策闭环 | 先规则路点基线，再适配 GameScaling | 与无地图基线比较；安全停止可现场验证 |
| 5：自主 NPC | 任务、状态、记忆与长期执行 | 多场景重复实验，报告成功率与失败原因 |

阶段 1 及之后均未在公开仓库中宣称验收完成。大型接口调整先通过 Issue 讨论输入输出和可复现验收；研究性设想在获得证据后再进入正式介绍。
